# Project Overview

Welcome to the **eco-IE** project! This project focuses on Named Entity Recognition (NER) tasks, leveraging both baseline and fine-tuned Large Language Models (LLMs) to identify and classify entities in textual data.

## Directory Structure

### 1. `src/`
- **Purpose**: Contains the source code for the project.
- **What to do here**: Explore this directory to review or modify the codebase.

### 2. `baseline-LLM-Output/`
- **Purpose**: Stores the results & outputs generated by the project, specifically for the baseline LLM model implementations, including reasoning, few-shot, and zero-shot approaches.
- **What to do here**: Check this directory to view the output files or results.

### 3. `finetuned-LLM-Output/`
- **Purpose**: Stores the results & outputs generated by the project, specifically for the fine-tuned version of the Qwen2.5-14B-Instruct Model.
